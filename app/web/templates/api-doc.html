网站 SEO 审计与页面证据

Demo 默认 SEO 审计，知识图谱按需开启
网站 SEO 审计（task_type=site_seo_audit）未开启 Full Audit 时最多采样 8 页；开启后默认 12 页，max_pages 范围为 5–10000。综合评分包含 Technical SEO、Content Quality、On-Page SEO、Schema、Performance、AI Search / GEO；配置权重分别为 22、23、20、10、10、10，计算时按总和 95 归一化。性能为启发式评估，未接入真实 CrUX/PSI。
站点链接展示当前任务发现的 URL。仅采样页面有抓取测量，历史记录中缺失的值显示“未记录”。新抓取会记录时间、状态码、响应耗时、部分响应头，并单独缓存 HTML 源码（每份最多 2 MB，超限标记截断）。源码以纯文本展示，缓存位于 CACHE_DIR/page-sources，不随任务轮询重复传输。
GET/api/v1/demo/tasks/{task_id}/pages
GET/api/v1/demo/tasks/{task_id}/pages/{page_id}/source

以上 Demo 证据接口遵循现有 X-Demo-Token 访问验证；page_id 来自对应任务的链接列表。
