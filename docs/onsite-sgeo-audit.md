# SGEO 统一诊断规则

`site_geo_audit` 沿用原任务标识，产品名称改为“网站 SGEO 诊断”。评分版本 `onsite-sgeo-v1`。不再并列输出两套报告，也不对SEO、GEO总分或维度分做平均。

## 六维与检查归属

| 维度 | 权重 | 唯一检查 |
|---|---:|---|
| 可获取：访问、抓取与性能 | 20% | HTTPS/HTTP、检索爬虫规则、访问挑战、抓取稳定性、HTML耗时、移动视口、HTML体量、图片资源与加载策略 |
| 可发现：页面发现与索引 | 15% | 导航内链、导航链/Sitemap、Canonical/跳转、索引与摘要指令、llms.txt、URL参数规范 |
| 可理解：正文读取与信息提取 | 15% | 核心正文、信息载体、原始/渲染正文对照 |
| 可引用：内容价值与答案适配 | 25% | 主题对应、关键信息、段落组织、页面任务信息、具体表达与低冗余 |
| 可信赖：主体、依据与时效 | 15% | 发布主体、主张来源、日期版本、跨页事实核验 |
| 可识别：元数据与实体语义 | 10% | 标题/描述/语言、实体命名、适用Schema与正文一致、多语言版本声明 |

共30项检查、满分100分。标题、内链、Schema、图片替代文本等重叠检查各自只有一个计分归属。标题/描述不设固定字符数，不要求每种页面都满足统一字数、FAQ或Schema类型数量。

规则定义以 `app/services/audit/sgeo.py` 的 `DIMENSIONS`、`RULES` 为准；在线 `/api-doc#sgeo-scoring` 逐项展示积分与修复建议，并由测试核对一致性。

## 计分与证据

每页独立检测。页面类型等权，同类型页面等权，失败页面保留在样本中。聚合每条检查时，仅在适用页面间归一；待核验页面仍进入证据覆盖率的分母。

- 维度分 = 已获积分 ÷ 已测积分 × 100。
- SGEO暂定总分 = Σ（已测维度分 × 维度权重）÷ 已测维度权重之和。
- 证据覆盖率按适用维度权重加权；分数下界将未知项按0分、上界按满分处理。
- 不适用项从该维度的适用积分中排除；整个维度不适用时才从适用权重中排除。
- 访问拒绝、爬虫阻止、noindex或正文不可读取等阻断独立保留。即使测得较高暂定分，状态仍为 `blocked`。
- 抓取稳定性、未测渲染、缺少审核依据的跨页事实保持 `unknown`；未知不当作通过，也不虚构问题。

HTML获取耗时使用800/1500/3000/5000ms分档；HTML体量使用250,000/1,000,000字节的产品启发式预算，不冒充 Core Web Vitals。移动端只检查viewport声明，图片检查资源可发现性与显式高优先级/懒加载冲突，不要求首屏图片懒加载。多语言仅核对已声明的链接，无声明且源码未截断时为不适用，不声称已验证版本互返。

llms.txt只占1分，属于辅助发现入口。分析代码、社交卡片、一般安全头、训练授权、站外权威和平台曝光不计分。纯SEO仍可按其独立规则使用相关支持信号。

SGEO是站内搜索与生成式检索就绪度，不代表实际收录、排名、真实爬虫访问或AI引用概率。语义规则是结构代理；AI配置不改变分值。

## 任务与结果

流程：`discovery → sgeo → observation → summary`。只采集一批页面证据，复用GEO基础检查的观察结果并补充搜索信号，不运行SEO完整评分引擎，不请求Semrush。

新任务结果包含：

- `result.sgeo.score`：统一总分；`scoring_version`、`status`、`provisional`、`score_range` 一并读取。
- `result.sgeo.dimensions`：唯一的六维评估，每项检查以 `SGEO-001` 至 `SGEO-030` 标识。
- `result.sgeo.pages`、`blockers`、`coverage`：逐页证据、阻断和覆盖率。
- `summary.sgeo_score`：统一摘要分数；`overall_score`、`combined_score`为同一分数的兼容别名。
- `result.observation`：独立观测，不计分。

新SGEO任务不再返回 `result.seo`、`result.geo`、`seo_summary`。调用方从原组合类型迁移时，应改读 `result.sgeo`。纯SEO、纯GEO和历史同步模块接口不变。

## 展示与历史兼容

沿用GEO报告的概览、问题表、完整清单、六维卡片和逐页证据样式。只显示一个总分、一张雷达图、一组六维卡片和一份行动清单；按维度和优先级筛选，保留影响、修复与验收条件。Markdown导出使用相同的统一模型。

新SGEO缓存包含SGEO版本、基础观察规则版本和渲染开关，与旧组合结果隔离。已有双分结果通过保存的页面检查和成功抓取快照重新归并为SGEO视图；未保存的新测量保持待核验。该过程不请求网络、不改写存储的旧评分。原分与新SGEO分不能直接横比，补齐新增检查需重新诊断。

独立SEO和GEO继续保留原规则与评分含义。共同基础能力的设计参考[Google对AI搜索功能的说明](https://developers.google.com/search/docs/appearance/ai-features)，具体分值和权重为本产品的诊断设计。
